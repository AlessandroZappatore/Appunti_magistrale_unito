## 🧭 Argomenti trattati finora

1. **Introduzione**: applicazioni mission critical, Enterprise Application Integration, requisiti non funzionali, dal modello a cascata a Lean e Agile, cloud come piattaforma, architetture a microservizi e cultura DevOps
2. **Requisiti per architetture a microservizi**: monolite vs microservizi, SOA, legge di Conway, Domain-Driven Design (ubiquitous language, user stories, CRC cards), DDD strategico (sottodomini, bounded context, shared kernel, anti-corruption layer) e tattico (entity, value object, aggregate, factory, repository, service)
3. **REST**: chiamate remote, API su HTTP in stile RPC, risorse, verbi e status code REST, REST vs RPC, API esterne e interne
