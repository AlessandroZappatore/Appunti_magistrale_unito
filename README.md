# 📚 Appunti Magistrale in Informatica (UNITO)

Appunti, formulari ed esercizi che ho preparato per gli esami della **Laurea Magistrale in Informatica** all'Università degli Studi di Torino. 📘🎓

Quasi tutto il materiale è scritto in LaTeX: sono appunti presi a lezione e poi riscritti, integrati con le slide del corso e revisionati.

## 📥 Come scaricare il materiale

- **Un solo file:** apri il PDF su GitHub e usa il pulsante *Download raw file* (icona ⬇️ in alto a destra).
- **Tutta la repository:** *Code → Download ZIP* (circa 70 MB), oppure
  ```bash
  git clone --depth 1 https://github.com/AlessandroZappatore/Appunti_magistrale_unito.git
  ```
  `--depth 1` scarica solo l'ultima versione dei file, senza le vecchie versioni dei PDF salvate nella cronologia.

## ⚠️ Avvertenze

Sono appunti personali: nonostante la revisione possono contenere errori, imprecisioni o parti incomplete. Non sostituiscono le lezioni, le slide e i libri di testo indicati dai docenti, quindi in caso di dubbio fa fede il materiale ufficiale del corso.
